Every New Tab,
Organized Your Way

MorrowTab replaces the new tab in Chrome and Edge with boards of links you actually use, a search box that runs through your browser's own default provider, and a daily FixQuotes quote. Keep one board for work and another for everything else, each with its own columns, links and extra search engines. They travel through the browser profile you are already signed into, so there is no MorrowTab account to create and no MorrowTab server holding your data.

Features

What MorrowTab Actually Does

A new tab page, a toolbar Quick Save, and a set of controls that stay out of the way until you want them.

🗂️

Boards for different contexts

Each board owns its own columns, links, extra search engines and ordering, so work, personal and research links never share a screen.

  • Switch boards from the picker or with Alt + 1–9
  • Move a whole column to another board in one step, with undo
  • The active board is remembered per computer, not synced
🔍

Search that stays yours

Browser default is always first and always selected on a fresh tab. It submits through your browser's own configured provider — MorrowTab never sets or replaces your default search engine.

  • Add engines from any HTTP(S) template with {query}
  • Share one engine across every board, or keep it to a single board
  • / or Ctrl + K focuses the search box
🌅

A daily quote, and an optional photo

The FixQuotes Quote of the Day shows as text at the bottom by default, or as a picture above or below your cards. Turn it Off and MorrowTab makes no quote request at all.

  • Four modes: Text, Picture (bottom), Picture (top), Off
  • Opt in to one curated Pexels nature photo a day, with its photographer credit
  • Or upload your own background, kept on that computer only
🔄

Sync without an account

Boards, columns, links, search engines and shared settings ride your browser's own extension sync. There is no MorrowTab login and no MorrowTab server holding a copy.

  • Every write is taken under a lock and checked against the data it was based on
  • Export and import a plain JSON backup of everything synced
  • If two computers ever merge badly, you get a read-only recovery view instead of a broken page
🎨

Nine backgrounds and two densities

Auto follows your system between a plain white page and a dark surface. The other eight are gradients: Purple, Blue, Green, Pink, Dark, Teal, Red and Violet.

  • Comfortable or compact column spacing
  • Capped cards or fill-each-row layout — columns wrap, never scroll sideways
  • Give any column one of eight accent colors, or none
⌨️

Keyboard and undo throughout

Boards start locked so a stray drag cannot rearrange them. Unlock to reveal the drag handles, then move things by dragging one or by focusing one and pressing Alt plus the arrow keys.

  • Deleting a board, column or link leaves a six-second Undo in the toast
  • Alt + Shift + S opens Quick Save from anywhere
  • Unlocking is per-tab and never saved, so every new tab starts locked
💡

Keyboard

Without Touching the Mouse

Everything you rearrange by dragging can also be moved from the keyboard, and the search box is a single keystroke away.

The shortcuts you will use most. The manual documents the rest, including menu typeahead and the Background color swatches.
Keys What it does
/ or Ctrl + K Focus the search field from anywhere on the page
Alt + 1 … 9 Switch to the first through ninth board
Alt + ↑ / ↓ Cycle the board’s search engines, from inside the search field
Alt + arrow keys Move a column, link, board or search engine while a drag handle has focus
↑ ↓ Enter Esc Move through saved suggestions, accept one, or close the panel
Alt + Shift + S Open the Quick Save popup from any tab

/ is ignored while the caret is already in a text field, so Ctrl + K is the one to use while typing. Neither fires while a dialog or a menu is open. Alt + Shift + S is a suggested default — Chrome silently declines a shortcut that collides with one you already have, so check or change it at chrome://extensions/shortcuts.

Privacy

Where Your Data Goes

The short version. The privacy policy lists every storage key and every request by name.

Synced through your browser

Board names, column titles, link titles and URLs, search templates, shared settings and a per-link click count go into chrome.storage.sync — the browser's own extension sync, tied to the profile you are signed into.

Chrome extension sync is not end-to-end encrypted, so treat board names and saved addresses as non-confidential.

Kept on one computer

Your selected board, saved search suggestions and whether new ones are recorded, an uploaded background, the cached nature photo, the cached quote, the remembered Quick Save destination and two safety snapshots stay in local extension storage.

None of them syncs, and none of them is included in an exported backup.

Three fixed addresses

fixquotes.com for the daily quote, plus api.fixquotes.com and images.pexels.com for the opt-in nature background, plus one site you name yourself if you switch on page-title autofill. The two FixQuotes requests carry no cookies, no referrer and no query string; the Pexels image URL carries only the sizing parameters FixQuotes chose.

The daily quote is on by default; setting it to Off stops the request entirely.

Questions

Common Questions

Does MorrowTab change my search engine?

No. The default option is called Browser default, and it hands your query to whatever provider Chrome or Edge is already configured with. MorrowTab never sets, replaces or proposes a search engine of its own, and it ships with no provider preconfigured. Any extra engine in the list is one you added yourself.

What does it cost?

Nothing. MorrowTab is free, with no paid tier, no trial period and nothing to buy inside the extension. There is no account to upgrade, because there is no account.

Do I need an account?

No. There is no MorrowTab account, no login, and no MorrowTab server. Your boards are stored by your browser’s own extension sync, which follows the browser profile you are already signed into. If that profile is syncing extension data, your boards appear on your other computers with nothing else to set up; if it is not, they simply stay on the one computer.

Does MorrowTab connect to the internet?

Only for features you can switch off, and only to addresses you can name in advance. The daily quote is set to Text out of the box and fetches fixquotes.com once per local day; setting it to Off stops that entirely. If you switch on the optional daily nature background, MorrowTab asks api.fixquotes.com which photo to show and fetches it from images.pexels.com. One more address is possible, and only if you ask for it: with Fetch page titles when adding links switched on, MorrowTab requests the one site whose address you just typed, after your browser asks your permission for it. Nothing else, and no analytics.

Can it read the pages I browse?

No. MorrowTab has no content scripts, so it never runs on the sites you visit. The toolbar popup sees the title and address of the tab you are on, and only at the moment you click the button. The one exception is entirely up to you: if you switch on Fetch page titles when adding links, Chrome asks your permission for each individual site before MorrowTab reads that page’s title.

How much can I save?

Up to 30 boards, 120 columns (40 per board), 250 links (200 per column) and 80 search engines, inside a 100 KB sync budget. Those are deliberate ceilings set below what browser extension sync allows, so a save fails with a clear message rather than quietly losing data. Settings shows how much of the budget you are using.

Is my data encrypted?

Not by MorrowTab. Browser extension sync is not end-to-end encrypted, so treat board names, link titles, saved addresses and search templates as non-confidential. Exported backups are plain, readable JSON files, and the records MorrowTab keeps on your own computer are stored in plain text under your browser profile.

Which browsers does it work in?

Google Chrome and Microsoft Edge on Chromium 114 or newer. That floor is real: MorrowTab relies on the Popover API, Web Locks, CSS :has() and color-mix(). There is no Firefox or Safari build.

Can I get my data out again?

Yes. Settings exports everything synced — boards, columns, links, search engines and shared settings — as one readable JSON file saved to your own computer, and imports it back. You can also export a single column and drop it into another board. Backgrounds, saved search suggestions and cached images stay on the computer that made them and are deliberately excluded from the file.
