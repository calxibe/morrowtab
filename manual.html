MorrowTab User Manual

MorrowTab replaces the new tab in Chrome and Edge with a board of your own links, a search box that runs through your browser's own provider, and a daily quote from FixQuotes. This manual walks through every screen and every setting in the order you are likely to meet them — from the starter board a fresh install shows you, through boards, columns, links and search engines, to backups, storage limits, keyboard shortcuts and what to do when something looks wrong.

Covers MorrowTab 1.0.0 · Chrome and Edge 114 or newer

What MorrowTab does

MorrowTab is a browser extension that takes over the new tab page. Instead of a blank page or a grid of most-visited thumbnails, every new tab opens a board: a set of columns, each holding links you put there yourself, with a search box across the top and — unless you turn it off — a quote of the day at the bottom.

You can keep as many boards as you need, up to thirty. Each board owns its own columns, links, extra search engines and their ordering, so a work board and a private board never share a screen. The browser tab title follows the board you are on, reading Board name — MorrowTab.

The three surfaces

  • The new tab page. Boards, columns, links, the search box, the layout lock and the Settings dialog all live here.
  • The toolbar popup. Clicking the MorrowTab button on any website opens Save to MorrowTab, which files the page you are looking at into a board and column without leaving the tab. See Quick Save from the toolbar.
  • The welcome page. Shown once, on a genuine first install. It is an introduction, not a release-notes page, and it does not reappear after an update.

What it is not

MorrowTab has no account and no MorrowTab server holding your data. Your boards travel through the extension sync your browser already runs for the profile you are signed into. There is no bookmark import, no tags, no widgets, no to-do list and no AI features — a link carries a title, an address, an optional one-line description, an optional Opens in override, and a count of how often you have opened it.

🌐

MorrowTab is not an offline-only extension

The daily quote is set to Text out of the box, and in that mode MorrowTab asks fixquotes.com for the quote of the day once per local day. Setting the quote to Off stops that request entirely. The curated nature background is separate and is off until you switch it on. Those are the only features that reach the network on their own.

Installing MorrowTab

📦

MorrowTab 1.0.0 is not published yet

MorrowTab is on its way to the Chrome Web Store and Microsoft Edge Add-ons. It is not listed on either store today, so there is nothing to install yet. This page will carry direct links to both listings the day they go live.

What installing will involve

Once the listings are live, installing MorrowTab is an ordinary one-click store install — the same Add to Chrome or Get button as any other extension. Nothing needs to be downloaded by hand, unpacked, or configured first. After the install completes:

  1. The new tab is taken over. MorrowTab's manifest overrides the new tab page, so every new tab opens MorrowTab once the extension is enabled, subject to whatever confirmation your browser shows for an extension that changes that page.
  2. A welcome page opens once. It is a short introduction to Quick Save, boards and search, unlocking the layout, the quote modes, and the boundary between what syncs and what stays on that computer. It appears only on a true first install, never after an update or a browser restart, and it cannot be reopened from inside the extension.
  3. The starter board appears. Your first new tab shows a ready-made Popular websites board. It is rendered from a file inside the extension and nothing is written to sync until your first edit — see Your first board.

Requirements

  • Google Chrome or Microsoft Edge on Chromium 114 or newer. That floor is declared in the extension itself.
  • Chromium 114 is the minimum because MorrowTab's menus, search autocomplete and toasts use the Popover API, and the rest of the app relies on Web Locks, CSS :has() and CSS color-mix().
  • There is no Firefox or Safari build, and no mobile version. Chrome and Edge on the desktop are the supported browsers.

You do not need sync to use MorrowTab — it works on a single computer as it is. Sync is only what carries your boards to a second computer, and it is your browser's own, so there is no MorrowTab account to create for it. See How syncing works.

Your first board

A fresh install opens on a board called Popular websites. It holds exactly 50 links in five columns of ten: News, Streaming, Social media, Everyday tools and Shopping. No search engines are configured on it — Browser default covers search without putting any provider into your synced data.

The starter board is virtual until you change something

While your synced storage is empty, that board is read from a file bundled inside the extension. Opening or reloading a new tab does not write it anywhere. The first time you actually change something — rename a column, delete a link, add a board — MorrowTab takes a lock, checks once more that nothing has arrived through sync in the meantime, and then writes the whole starter board plus your change in a single save. That is the same protected write every later change uses — see How syncing works.

One thing to expect from that first save: the starter board stops being a template and becomes ordinary data of yours, so its 5 columns and 50 links start counting towards your totals. Anything you do not want is yours to delete.

Two consequences worth knowing. First, if data does arrive through sync while the starter is on screen, your pending change is stopped and the page refreshes to show the real data rather than overwriting it. Second, the starter is never merged into storage that already has content, so a future update to the bundled starter can never bring back a link or column you deleted.

Making it yours

  • Delete what you do not want. Deleting a link, column or board leaves a six-second Undo button in the toast.
  • Rename a column in place from its ⋯ menu.
  • Add links with the large + button at the foot of a column card.
  • If you empty a board completely you get the prompt "Build this board your way" and a Create the first column button.

Which board opens

The board you last selected is remembered on that computer only, not through sync. A laptop and a desktop signed into the same profile share every board, but each can sit on a different one.

Managing boards

The picker at the top left switches boards. Its last entry, Manage boards…, opens the dialog where boards are created, renamed, reordered and deleted.

Creating and renaming

Add board opens a dialog titled New board with one field, Board name, and the placeholder "For example, Cyber security". The button reads Create board. Renaming reuses the same dialog with the title Rename board and the button Save name.

A new board starts empty. It reuses any search engines you marked as visible on all boards, but MorrowTab never invents a search provider for it.

Reordering

Drag a board's handle, or focus the handle and press Alt + ↑ / Alt + ↓. The order matters beyond appearance: Alt + 1–9 jump to the first nine boards in exactly this order. Boards past the ninth have no shortcut.

Deleting

Deleting asks first, spelling out what goes with it: "This removes the board, its n columns, n links, and n board-only search engines. Search engines visible on all boards remain." The dialog closes itself so the six-second Undo in the toast is not stranded behind it.

You can never end up with zero boards. On the last remaining board the delete button is disabled, with the tooltip "At least one board is required".

What is per board and what is shared

  • Per board: columns, links, which extra engines appear, their order, and their order.
  • Shared across every board: the background color, spacing, board layout, the daily quote mode, the background mode, usage ordering, and both "open in a new tab" settings.
  • Per computer: which board is currently selected.

Columns

A column is a card with a heading and a list of links. Columns wrap onto new rows when another readable card no longer fits — MorrowTab never turns the board into a horizontal strip you have to scroll sideways.

Creating a column

On an empty board, use the Create the first column button. Otherwise use the + button in a column card's header. Either way you get a dialog titled New column with the field Column heading, the placeholder "For example, Current projects", and a Create column button.

The column menu

Its entries, in order:

  • Open all links (n) — opens every link in the column as background tabs. Disabled when the column is empty. At eight links or more it asks first: "This opens every link in column in its own background tab." with an Open all button. Fewer than eight open straight away.
  • Rename column — closes the menu and turns the heading into a focused input. Enter saves and returns focus to the options button; Esc cancels; clicking away also saves. An empty name is refused with "Column name cannot be empty."
  • Move to board… — swaps the menu for a second page headed "Move column to" with a Back item and one entry per other board. It is disabled when only one board exists, and a destination already holding 40 columns is shown disabled. The move carries all the column's links in one save, with Undo.
  • Export column — downloads that one column and its links as a JSON file named after the column. See Backup, export and import.
  • Color — a row of swatches: No color plus blue, purple, yellow, amber, green, teal, red and gray. Each swatch is announced by its own name — "blue accent", "teal accent", and so on — and No color is announced as "No color". Applying one confirms with "Column color saved"; No color gives "Column color cleared".
  • Delete column… — confirms with "This removes the column and its n saved links from Sync." and leaves a six-second Undo.

The menu is fully navigable with ↑ and ↓, swatches included.

Empty columns and long columns

An empty column shows "No links yet" — or "Drop links here" while the layout is unlocked. Once a column holds six or more links it switches automatically to a denser row style with smaller icons, so a long list stays readable. A column holds up to 200 links, and you can have 40 columns on a board and 120 across all boards.

Adding and editing links

The large + button at the foot of a column card adds a link there; its label and tooltip name the column. Hovering or focusing an existing link reveals a pencil button that opens the same dialog in edit mode.

The fields

  • Web address — placeholder https://example.com. Only http and https addresses can be saved, up to 2,048 characters. If you leave the scheme out, MorrowTab prepends https:// before validating.
  • Name (optional) — placeholder "A friendly name". Left empty, the link falls back to the address's hostname.
  • Description (optional · 200 characters) — placeholder "A short note shown beside the link name". It appears as a second line on the card.
  • Column — with more than one board, this select groups every board's columns with the current board first, so a link can be moved to another board from the editor. Its click count and its Opens in choice travel with it.
  • Opens in — Follow the shared setting, New tab, or Current tab. This is the per-link override of the Settings toggle Open saved links in a new tab.

Deleting a link is only available inside the Edit link dialog. It confirms with "This link will be removed from the current board." and leaves a six-second Undo.

Duplicates are warned about, not blocked

Saving an address the destination board already holds shows an inline warning naming the column and title it is already in, and ending "Choose Add link again to keep both." Pressing the button a second time keeps both copies. The second press only counts after a short delay, so a double-click or a held Enter cannot skip past the warning.

Other inline messages

You may also see "Enter a valid http or https address.", "Choose a destination column. Create a column first if none exists.", a column-full message naming its 200-link ceiling, "No more than 250 links can be synced.", or "This link changed on another synced device. Close the editor and try again."

Two faster ways in

  • Drag from outside. Drag a link from your bookmarks bar, another tab or the address bar onto a column card and it is added there, with an Undo in the toast. Dropped files are ignored, and anything that is not an http(s) address is refused with "Only http(s) addresses can be dropped here." The title comes from the dragged link's own text, or from the hostname with a leading www. removed.
  • Paste. Paste an http or https address anywhere on the page — not into a field — and the Add link dialog opens with the address already filled in and the caret in Name.

Fetching page titles

Settings has a toggle Fetch page titles when adding links, described as "Off by default. When enabled, MorrowTab asks for access to each entered site and uses its page title only when Name is empty." Two separate opt-ins are needed: the setting itself, and Chrome's own permission prompt for that one site the first time you commit an address in the field. Decline and you simply see "Allow site access to fetch the page title." and type the name yourself. Title fetching never runs while you are editing an existing link, and never overwrites a name you typed.

Link icons

Each link shows a badge. MorrowTab tries a brand icon bundled inside the extension first, then the browser's own local favicon store, then a two-letter badge built from the title. It downloads no icons and calls no icon service. If the browser's favicon access is unavailable at startup you may see a warning suggesting a reload or reinstall from chrome://extensions; links keep working, with bundled icons and initials.

Searching from the new tab

The search field takes focus the moment a new tab opens, so you can start typing straight away. Press Enter or the Search button to submit.

Browser default

The engine picker between the field and the button always lists Browser default first, and every fresh page starts on it. It hands your text to Chrome or Edge, which runs it through the provider that browser profile is already configured with. MorrowTab does not set, replace or hijack your default search engine, and it never sees your query on a server of its own. Browser default cannot be renamed, reordered or deleted, and it is not stored as a synced record.

Reading the placeholder

The placeholder tells you which engine is armed: "Search with browser default" for the built-in option, "Search with name" for one of your own, and "Chat with name" when the template points at chatgpt.com or one of its subdomains. If no engine can be resolved at all it reads "Search unavailable".

Where results open

Results replace the current tab by default. Turn on Open searches in a new tab in Settings and they open beside it instead — the board stays on screen and your query is re-selected in the field, so the next search types straight over it.

Keyboard

  • / focuses the field and selects what is in it — but only when the caret is not already in a text field.
  • Ctrl + K (Cmd + K on a Mac keyboard) does the same and works even while you are typing somewhere else on the page.
  • With focus in the field, Alt + ↑ and Alt + ↓ cycle through that board's engines, wrapping around.

The field's own tooltip says the same thing: "Press / to focus search. Alt + up or down arrow switches the search engine."

Adding your own search engines

Beyond Browser default, each board can carry its own engines — a documentation site, an internal wiki, a package index, whatever that board is for. Open the engine picker and choose Manage search engines…, or reach the same dialog from the picker at any time.

Adding one

Press Add search engine and fill in two fields:

  • Name — what the picker shows, for example VirusTotal. The field accepts up to 60 characters; the stored limit is 80.
  • Search URL template — the engine's own search address with {query} where your typed text should go, for example https://example.com/search?q={query}. The help text under the field reads "Use {query} or <input> where the typed search should go." The older <input> placeholder is accepted and quietly rewritten to {query} when the engine is saved.

The template must be a valid http or https address of at most 2,048 characters. Anything else is refused inline with "Use a valid http or https URL containing {query} or <input>." Your typed text is percent-encoded before it is inserted, and the search is an ordinary navigation to that address — it does not pass through anything of MorrowTab's.

One board or all of them

The Visible on all boards toggle decides scope. Its own help line puts it plainly: "Turn this off to keep the search engine only on the current board." An engine marked for all boards is one record referenced everywhere, but each board still keeps its own ordering, so the same engine can sit second on one board and fifth on another.

Reordering, editing and deleting

Drag an engine's handle to reorder it, or focus the handle and press Alt + ↑ / Alt + ↓. Deleting asks first, and the wording depends on scope: "This search engine will disappear from every board." for a shared engine, or "…from the current board." for a board-only one. You can delete the last additional engine — Browser default is always there.

🔢

Twenty per board, eighty in total

When a board already holds twenty engines, Add search engine is disabled with the tooltip "A board can have up to 20 search engines". Marking an engine as visible on all boards is refused if that would overfill some other board, with a message naming it.

Saved search suggestions

Searches you have actually run come back as suggestions the next time you type. They are your own past queries and nothing else — MorrowTab does not fetch completions from Google, Bing or any other provider, and it never sends what you are typing anywhere to build the list.

How the list behaves

  • Nothing appears until you have typed five characters. Below that the screen-reader status says how many more are needed.
  • It matches anywhere inside a saved query, not just at the start.
  • At most eight suggestions are shown at a time.
  • Each search engine keeps its own history of up to 50 queries, newest first, de-duplicated without regard to capitalization.
  • Queries are stored up to 512 characters; whitespace is collapsed and control characters are stripped before saving.
  • When you delete a search engine, its saved queries are dropped on the next load.

Keyboard

↓ and ↑ move through the list and wrap around, opening it if it was closed. Enter accepts the highlighted suggestion into the field without submitting, so you can edit it first. Esc closes the list and leaves your typing alone, and Tab closes it as you move on.

Turning it off and clearing it

Settings has a toggle labeled Save search suggestions, described as "Queries you submit are stored only on this computer and never synced. Turning this off keeps existing suggestions but stops saving new ones." It is on unless you turn it off.

The Clear saved suggestions button beneath it asks "Clear saved search suggestions?" and warns that this "permanently removes all saved search suggestions from this computer. It does not change whether future searches are saved." The button is disabled when there is nothing stored.

💻

Suggestions stay on one computer

Saved queries live in your browser's local extension storage. They are never synced to another computer and never included in an exported backup. What you search for still goes to the search engine you chose, exactly as if you had typed it in the address bar — only the suggestion list is local.

Quick Save from the toolbar

The MorrowTab toolbar button — tooltip Save to MorrowTab — files the page you are currently on into a board and column without leaving it. It works on any website, whether or not you use the new tab page.

What the popup shows

  1. The heading Save to MorrowTab.
  2. A Current tab preview: the page title on one line and the address beneath it.
  3. The hint "Choose a destination, then save."
  4. Board and Column selects, a Title field prefilled from the page, a status line, and the Save current tab button.
  5. An Open MorrowTab button underneath, which opens the new tab page.

Quick Save stores exactly four things: the board, the column, the title you leave in the field, and the page's address. There are no notes, tags, highlights or page captures.

Where it saves by default

The destination you used last is remembered on that computer and preselected next time, as long as that board still exists — otherwise the popup falls back to the board the new tab page is currently on. The remembered column is only reused when it is still part of the chosen board; otherwise the first column is selected. Because this preference is local, it does not follow you to another computer.

The New “Saved” column option

The Column list always ends with an entry that creates a new column called Saved on that board. Choosing it creates the column and saves the link in one write, so you can file something into a board that has nowhere obvious to put it.

Duplicates

Saving an address the destination board already holds shows "Already saved on this board in column. Save again to keep both." Pressing Save current tab a second time keeps both copies. As in the full editor, the second press is only accepted after a short delay, and the warning resets if you change the board.

What can and cannot be saved

Only http and https pages. On a chrome:// page, a file:// page or another extension's page the Save button stays disabled and the popup explains why: "Only http(s) pages can be saved." An address that is too long or otherwise invalid gives "This page's address is too long or invalid to save."

On success the status line reads "Saved to MorrowTab ✓" and the popup closes itself a moment later. If your synced data changed while the popup was open, or a limit is in the way, you get plain-language messages instead — "Synced data changed — pick a destination and try again.", "Synced storage is full. Open MorrowTab to tidy up, then try again.", or "That board or column is full. Open MorrowTab to tidy up, then try again."

⌨️

The shortcut opens the popup — it does not save on its own

Alt + Shift + S is MorrowTab's suggested shortcut for opening Quick Save. You still choose a destination and press Save. Chrome silently declines a suggested shortcut that collides with an existing one, so confirm or change it at chrome://extensions/shortcuts.

Rearranging things

Every new tab starts with the layout locked, so a stray drag can never rearrange a board you were only reading. The padlock button beside Settings unlocks it: its accessible name switches between "Enable drag and drop" and "Disable drag and drop", and its tooltip between "Unlock layout" and "Lock layout".

Unlocking shows the toast "Drag and drop enabled — drag a handle or press Alt + arrow keys"; locking again shows "Layout locked". The unlocked state belongs to that one page: it is never saved, never synced, does not affect another open tab, and is back to locked after a reload.

With the mouse, a finger or a pen

  • Drag a column card's handle sideways. It drops before or after the card you are over depending on which side of its midpoint you release.
  • Drag a link's handle within its column or into another one. Dropping on empty space in a list appends to the end.
  • Dragging near the top or bottom edge of the board area scrolls it automatically.
  • Touch and pen dragging work through their own path, for columns, links, boards and search engines alike.

From the keyboard

Every drag handle is focusable and advertises its own shortcuts:

  • Column: Alt + ← / Alt + → moves it one position. Focus stays on the handle.
  • Link: Alt + ↑ / Alt + ↓ moves it inside its column; Alt + ← / Alt + → moves it to the previous or next column, appended at the end. Focus follows the link.
  • Boards and search engines in their managers: Alt + ↑ / Alt + ↓.

Each move is announced for screen readers in the form "Moved name to position 3 of 5", and confirmed with a toast such as "Columns reordered" or "Link moved".

Undo

Undo is a button inside a six-second toast, not a Ctrl + Z history. It is offered for exactly six operations: deleting a board, deleting a column, deleting a link, moving a column to another board, importing a column file, and adding a link by dragging it in from outside. Renames, edits, reorders, color changes, settings changes and full backup imports are not undone this way.

Undo also refuses to fire if your synced data changed in the meantime, reporting "Could not restore — the surrounding data changed after deletion." That is deliberate: it can never overwrite newer work from another computer.

🔒

Usage ordering pauses manual link ordering

While Order links by most used is on, link drag handles are hidden and keyboard link moves are refused — the column is sorting itself. Columns can still be reordered. See Ordering links by how often you use them.

Ordering links by how often you use them

MorrowTab keeps a plain counter on each link. Opening a link with a normal click or a middle-click adds one; clicking its edit button does not. The counter holds no dates, no times and no sequence — just a number.

The setting

Order links by most used in Settings is described as "Each column sorts by how often you open its links. Manual link reordering is paused while this is on." Turning it on sorts every column by those counts, using a stable sort so links with equal counts keep the order you gave them.

Resetting

Reset usage asks "Reset link usage?" and explains that "This clears the stored click counts for every link on every board." The action button reads Reset and success shows "Link usage reset". If there is nothing to clear you get "No link usage is stored yet."; if another computer already cleared it, "No link usage is stored anymore."

🔄

Click counts are part of your synced data

The counter lives on the link's own synced record, so it travels with the link and is included in an exported backup. It is recorded whether or not usage ordering is turned on. Counting is also best-effort: when a link replaces the current tab, the write races the page leaving, so an occasional click may not be counted. Treat the numbers as a useful ordering signal, not as exact statistics.

Appearance and layout

The gear button at the top right opens Settings. On a wide screen it puts Background color and Backup on one side and the taller Layout and links column opposite; in a short or narrow window the sections stack and only the area under the fixed header scrolls.

Background color

The help text reads "Choose the background used across every board. Auto follows the system appearance; the other choices use gradients." There are nine swatches, in this order: Auto, Purple, Blue, Green, Pink, Dark, Teal, Red and Violet.

Auto is the default and the only flat one: a plain white page when your system is in light mode, and a dark gray surface when it is in dark mode, switching live as the system does. The other eight are gradients. There is no separate light/dark switch — Dark is simply one of the nine choices, and everything else follows the operating system.

The swatches behave as a radio group: ← → ↑ ↓ move between them, Home and End jump to the ends, and each keypress applies and saves that background immediately.

The background is a single shared setting used on every board, not a per-board choice. Modal dialogs deliberately do not take the tint: they use one dedicated light or dark palette chosen by your system setting, so text in a form never has to fight a gradient.

Column spacing

Two options, Comfortable (the default) and Compact. Compact tightens the padding so more fits on screen.

Board layout

Also two options, worded in Settings as:

  • Capped cards — readable columns wrap into centered rows. The default. Cards share each row up to a readable maximum, and an incomplete final row is centered.
  • Fill each row — columns expand across the available width. The same wrapping behavior, but cards stretch to use the whole row.

In both, cards size themselves to their contents, long titles are shortened with an ellipsis rather than wrapping, and columns wrap onto new rows instead of scrolling sideways.

Column accents

Color is set per column from its own menu rather than in Settings — eight accents plus No color. See Columns.

Where links and searches open

  • Open saved links in a new tab — "Individual links can override this in their editor." Off by default.
  • Open searches in a new tab — "The current tab keeps showing this board."

The daily quote

MorrowTab shows a FixQuotes Quote of the Day. The Settings control is a select labeled Daily quote, described as "Show the FixQuotes quote as text at the bottom, or as a picture above or below your cards."

The four modes

  • Text — the default. A compact strip fixed to the bottom of the page, with a fade so it never sits hard against your links, and a little extra scroll room so the last row can clear it.
  • Picture (bottom) — the same placement, with the quote's image.
  • Picture (top) — the quote moves into normal flow between the search toolbar and your cards. No fixed strip, no fade, no extra scroll room.
  • Off — the quote is hidden entirely, any bottom reserve and fade are removed, an in-flight load is aborted, and no request is made to FixQuotes.

If a picture mode has no usable image, or the image fails to load, MorrowTab shows the text in that mode's chosen position instead — without changing your setting. The mode itself is a shared setting that syncs with the rest.

📡

The quote is on unless you turn it off

In Text and both picture modes MorrowTab requests the quote of the day from fixquotes.com — a plain GET with no cookies, no referrer and no query parameters — at most once per local day. Choosing Off is the way to stop that request entirely.

When the network is not there

A catalog of 150 quotes ships inside the extension, so a quote is shown immediately at startup and is still shown with no network at all — the day's entry is picked from your local date, so it is the same quote all day. If a request fails, MorrowTab keeps the last quote it had rather than blanking the strip. Cached quotes are re-checked against the same rules every time they are read, and anything that no longer validates is discarded.

The quote itself renders as the text, an em dash, the author, and a FixQuotes source link; the picture modes swap in a linked image.

Nature photos and your own image

Two optional background images sit below Background color in Settings. Their shared help line reads: "Daily nature downloads one curated, high-resolution Pexels photo through FixQuotes and caches it only on this computer. An uploaded image takes priority; the theme still colors buttons and accents."

Daily Pexels nature

The checkbox Daily Pexels nature is off until you tick it — this one really is opt-in, and a fresh install makes no request for it at all. When it is on, MorrowTab asks the FixQuotes public API once a day for one manually curated photograph, downloads it from Pexels' own image host, verifies it, and caches a compact copy on that computer. The status line then reads "Today's curated Pexels nature photo is cached on this computer."

A credit chip reading Photo by photographer on Pexels is shown at the bottom left whenever the photo is displayed, with both names linked. It is required and it stays.

You cannot search Pexels or choose the photo — the collection is curated on the FixQuotes side, and the extension holds no Pexels key. A verified cache prevents repeated downloads; once it is a day old it stays on screen while the next photo is fetched, and it is kept if the fetch fails. Turning the switch off stops work in progress and removes the photo and its credit.

Your own image

Upload background image… takes an image file from your computer. MorrowTab scales it to at most 2,560 pixels on its longest side, re-encodes it as WebP to fit local storage, and confirms with "Background image saved on this computer". A picture that is still too large after compression is refused with "That image is too large even after compression."

Remove image appears once an image is set and takes you back to the plain background. An uploaded image always wins over the daily nature photo — while one is set, the nature background will not even fetch, and its status says "Your uploaded background is taking priority on this computer."

🖼️

Background images never leave the computer they are set on

Both the uploaded image and the cached nature photo are stored in local extension storage. They are not synced to another computer, and image bytes are never part of an exported backup. Set the background again on your other machine if you want it there too.

Backup, export and import

The Backup section of Settings introduces itself as "Save synced MorrowTab data to a plaintext file on this computer, or restore a saved backup." It holds three buttons and one live readout.

Export backup

Export backup writes morrowtab-backup-YYYY-MM-DD.json to your downloads and confirms with "Backup exported". The file contains four fields — the application name, a schema version, the time it was exported, and your synced records: settings and board order, boards, columns, links (with their click counts) and search engines.

It is a plain, readable JSON file. It is not encrypted and not password-protected, so store it the way you would store a document listing the sites you use.

What a backup does not contain

Everything device-local is excluded by design, and none of it is restored from a file:

  • Saved search suggestions and the "Save search suggestions" preference
  • An uploaded background image and the cached nature photo
  • The cached daily quote
  • Which board is currently selected
  • The remembered Quick Save destination
  • Both local safety copies described below

Import backup…

Importing a full backup replaces everything currently synced. It asks first, under the title "Replace synced data?", naming how many boards and links the file holds, and adding either that a copy of the current data stays on this computer, or that the action cannot be undone. The confirm button reads Replace; success shows "Backup imported".

The file is validated first: it must carry the settings record, must not claim a newer schema than this version understands, and must not contain the old active-board field that 1.0.0 no longer accepts. The whole graph is sanitized and checked against every storage limit before anything is written, and a partly-failed write is rolled back.

Restore pre-import copy…

Before any full replacement, MorrowTab copies what you had onto that computer. The button Restore pre-import copy… then appears in Settings, with a tooltip showing when the copy was taken. Restoring is itself a full replace, so the copies rotate and the operation stays reversible. Success shows "Pre-import copy restored".

Single columns

A column's own menu has Export column, which writes just that column and its links. Feeding that file back through the same Import backup… picker is recognized automatically and behaves quite differently: it is additive. The column is appended to the board you are on with fresh identifiers, nothing is replaced, no confirmation is asked, and the toast offers Undo. The toast also reports anything skipped, for example "Imported “Research” (12 links, 3 skipped)". A file that is not readable gives "That file is not a readable MorrowTab column export."; one that would not fit gives "The imported column does not fit within the board or link limits."

The usage readout

Under the buttons sits a live line in the form Synced data: 9 of 100 KB · 50 of 250 links, computed with exactly the same byte arithmetic a save uses, so it can never disagree with what MorrowTab will accept. It changes to a warning style once either figure passes 85%.

How much MorrowTab can hold

Browser extension sync is a small, shared budget rather than open storage, so MorrowTab enforces its own ceilings safely inside it. Every limit below is checked against the complete projected data before anything is written, and a save that would break one is refused with a message naming it — nothing is half-written.

Every limit MorrowTab 1.0.0 enforces before it writes.

Some input fields stop you a little earlier than the stored limit — the board-name box and the search-engine name box accept 60 characters, the column heading 80 in the dialog (the full 100 when renaming in place), and the link name 100. Descriptions and addresses use the same number in both places.

Every stored string is also cleaned before it is saved: control characters become spaces, runs of whitespace collapse to one, the value is trimmed, and anything left empty falls back to a sensible default such as "Untitled board" or the link's own hostname.

How syncing works

MorrowTab has no account, no login and no server of its own. Your boards are written to the extension sync storage that Chrome or Edge already runs for the profile you are signed into, and that is what carries them to another computer. MorrowTab never receives a copy.

What syncs

  • Board names and their order
  • Column headings, their order, and any accent color
  • Link titles, addresses, optional descriptions, per-link Opens in overrides, and click counts
  • Search engine names, templates, scope and per-board ordering
  • The shared settings: background, spacing, layout, quote mode, background mode, usage ordering and both "open in a new tab" toggles

What stays on one computer

Nine things are deliberately local and are never written to sync or included in a backup: the selected board, the remembered Quick Save destination, saved search suggestions and their on/off preference, an uploaded background image, the cached nature photo, the cached daily quote, and the two safety copies (a rolling last-good copy and a pre-replacement copy).

How a save is made

Every write takes an exclusive lock across all MorrowTab pages in that browser profile and then compares a fingerprint of the exact data it was based on. If anything changed in the meantime the save is refused rather than applied blindly, and you are told to review the refreshed board. If a write succeeds but a related cleanup fails, the change is rolled back — and the rollback will never overwrite a value that changed remotely while it ran.

If the browser cannot provide that locking, MorrowTab refuses to write at all rather than risk corrupting your boards across tabs. And when sync itself is full or rate-limited, the save simply fails with "Browser Sync is full or temporarily rate-limited. No local fallback was used." — MorrowTab does not quietly divert your data into local storage.

Two computers at once

The lock covers the pages on one browser profile, not two separate computers. Simultaneous edits on two machines still resolve as last-write-wins once sync catches up, and in rare cases a merge can leave the record set inconsistent — which is what the recovery view exists for. If an editor is open on something another device just changed, the editor closes itself with "An item being edited changed on another synced device. The editor was closed."

🔓

Extension sync is not end-to-end encrypted

Board names, column headings, link titles, saved addresses and search templates travel through your browser's sync service. Treat them as non-confidential: they are not the place for anything secret. Exported backups are plaintext for the same reason. Whether and how sync data is encrypted at rest is a matter for your browser's own sync settings, not something MorrowTab adds.

When sync goes wrong

If changes from several computers merge into a set of records that no longer hangs together — a column pointing at a board that is gone, say — MorrowTab does not guess and does not silently rewrite. It opens a read-only recovery view instead of a broken page.

What you see

A banner headed "Synced data needs repair." with a summary in this shape: "Changes from your computers merged inconsistently. Showing a read-only view — n boards and n links are safe; n records would change… This can also resolve by itself while your computers finish syncing."

That last sentence is worth taking seriously. If the other computer is still sending its changes, the state often settles on its own. Waiting is a legitimate first move.

While recovery is active your boards render read-only. The board picker, search and the three recovery buttons keep working; editing and Manage boards… do not.

The three buttons

  • Download snapshot — writes morrowtab-snapshot-YYYY-MM-DD.json containing the raw, unrepaired records. Do this first if you want a copy of the current state before anything changes.
  • Restore local copy… — shown only when this computer holds a usable last-good copy. It asks "Restore this computer's copy?" and states plainly that it "replaces the inconsistent synced data on every computer with the complete copy saved on this computer" and that "Changes made on other computers after that moment are discarded." This is a replacement, not a merge. If sync healed itself while the dialog was open you are told instead that "The synced data already recovered on its own — nothing was replaced."
  • Repair… — asks "Repair synced data?" and explains that it keeps everything shown on the boards, lists what would be dropped or corrected, and notes that "The repaired data will be written to Sync for every computer." Success shows "Synced data repaired".

Nothing is written until you confirm, and the repair is tied to the fingerprint of the exact state you were shown — so it cannot act on data that changed while the dialog sat open. There is no automatic self-healing.

The safety copies

MorrowTab keeps a rolling last-good copy of your records on each computer after every clean load, and writes a separate pre-replacement copy the moment a full replace runs. Both are local availability copies only — never part of your synced data and never in an exported backup.

Accessibility

MorrowTab is built to be used without a mouse and without relying on color, and those expectations are checked before a release rather than left to chance.

Keyboard and focus

  • The board picker, engine picker, daily quote select and column menus are custom menus that support arrow keys, Home, End, typeahead, Enter, Space and Esc.
  • Closing a dialog returns focus to the control that opened it. If that control was re-rendered away in the meantime, focus goes to the search field rather than nowhere.
  • Editors open with focus already in the field you need.
  • A dialog can be dismissed by clicking its backdrop, but only when the press both starts and ends on the backdrop — so drag-selecting text inside a field never closes it and throws away what you typed.
  • Drag handles publish their own shortcuts through aria-keyshortcuts, so a screen reader can announce them.

Announcements

  • Two live regions mirror every toast — one polite, one assertive for errors.
  • Reordering is announced as "Moved name to position 3 of 5".
  • The suggestion list reports its state: how many more characters are needed, that there are no saved searches for this engine, or how many suggestions are available.
  • Toasts render above open dialogs, so an Undo button is never stranded behind a modal.

Display

  • At 200% browser zoom the page and the board area must not gain a horizontal scrollbar, and Settings must stay inside the viewport with its content reachable and keyboard focus trapped. This is checked as a release gate.
  • In Windows high-contrast (forced-colors) mode, meaning is carried by system colors, explicit borders, selected-state highlighting and visible focus — never by gradients, shadows, translucency or background imagery.
  • prefers-reduced-motion is honored throughout.
  • Light and dark follow your system setting. Modal dialogs always use a dedicated light or dark palette rather than inheriting the page's gradient, so form text keeps its contrast whichever background you chose.
  • The layout is responsive down to 320 pixels wide; below about 1080 pixels the search form moves to its own full-width row so the toolbar controls cannot collide.

Troubleshooting

The most common questions, with what MorrowTab is actually doing in each case.

My boards have not appeared on my other computer

MorrowTab writes to your browser's own extension sync, so the other computer must be signed into the same browser profile with sync switched on and extension data included. Give it a little time — sync is not instant — and open a new tab to pick up changes.

Some things are meant not to travel: which board is selected, saved search suggestions, an uploaded background, the cached nature photo and the remembered Quick Save destination are all per-computer by design. If those are what you were expecting, they are working as intended.

A save failed and the page reloaded

When a write cannot be completed safely, MorrowTab reports the reason and refreshes rather than leaving the board in a half-saved state. Two messages are common. "Browser Sync is full or temporarily rate-limited. No local fallback was used." means your sync budget is exhausted or you have saved a great many times in quick succession — check the usage line in Settings and, if it is near 100 KB or 250 links, delete something. "Synced MorrowTab data changed before this edit was saved. Review the refreshed board and try again." means another tab or computer got there first; look at the refreshed board and redo the change.

I cannot drag anything

The layout starts locked on every page. Press the padlock button beside Settings — you should see "Drag and drop enabled — drag a handle or press Alt + arrow keys" and the drag handles appear. The unlocked state is per tab and is deliberately forgotten on reload.

If columns drag but links do not, check whether Order links by most used is on. That setting sorts columns for you and pauses manual link ordering by drag and by keyboard alike.

Pressing / does nothing

/ is ignored while the caret is in a text field. Use Ctrl + K (Cmd + K on a Mac keyboard), which works while you are typing elsewhere. Neither shortcut fires while a dialog or a custom menu is open — close it first.

Alt+Shift+S does not open Quick Save

That combination is only a suggested default. Chrome silently declines to assign a suggested shortcut that collides with something already bound, so it may never have been registered. Open chrome://extensions/shortcuts, find MorrowTab, and set the key combination you want. The toolbar button always works regardless.

The Save button in the popup is grayed out

Only http and https pages can be saved. On a chrome:// page, a local file:// page or another extension's page the popup says "Only http(s) pages can be saved." An unusually long or malformed address gives "This page's address is too long or invalid to save."

The button is also disabled until your synced data has loaded. If the popup reports "Synced MorrowTab data needs the full app first.", open MorrowTab with the button underneath — only the full app performs repairs — then try again.

Search suggestions are not appearing

Suggestions come only from searches you have already submitted on this computer, and the list stays closed until you have typed at least five characters. Each engine keeps its own history, so switching engines shows a different set. Check that Save search suggestions is on in Settings, and remember that clearing them or deleting a search engine removes that engine's history.

Search says it is unavailable

If Browser default cannot be reached you will see "Browser default search is unavailable. Reload MorrowTab after checking the extension's search permission." Reload the tab first. If it persists, check MorrowTab's permissions in your browser's extensions page. In the meantime, any search engine you added yourself still works — it is an ordinary navigation.

Links show letters instead of site icons

MorrowTab prefers a brand icon bundled inside the extension, then your browser's own local icon store, then a two-letter badge. A site with neither a bundled icon nor an icon your browser has already cached will show initials — that is the intended last step, not an error. If the warning "Favicons are unavailable" appears at startup, reload the page; if it persists, reinstall MorrowTab from chrome://extensions.

No quote is showing

Check the Daily quote setting first — Off hides it entirely. In Text or either picture mode, a quote should always appear: MorrowTab ships a catalog of quotes and falls back to it when the network is unavailable. If a picture mode shows text instead of an image, the image for today's quote could not be used; your setting is untouched and the picture returns when a usable one does.

The nature background is not changing

An uploaded background always takes priority — while one is set, the daily photo will not even be fetched, and the status says so. Remove the uploaded image first. Otherwise, a fresh photo is selected once a day; if a refresh fails, the previous verified photo stays on screen rather than leaving you with a blank background.

A "Synced data needs repair" banner appeared

Changes from two computers merged into a state MorrowTab will not guess about. Your links and search still work; the boards are read-only for now. The banner itself notes that this can resolve on its own while your computers finish syncing, so waiting a few minutes is a reasonable first step. If it does not clear, use Download snapshot to keep a copy, then Repair… — or Restore local copy…, remembering that restoring discards changes made on other computers after that copy was taken. Nothing is written until you confirm. See When sync goes wrong.

I imported a backup and lost what I had

Importing a full backup replaces everything currently synced — that is what the "Replace synced data?" confirmation warns about. Before the replacement MorrowTab copies your previous data onto that computer, so open Settings and look for Restore pre-import copy…. It only appears on the computer where the replacement happened.

Importing an exported column is different: it is additive, it does not replace anything, and the toast offers Undo.

Undo did nothing

Undo lasts six seconds and covers six operations only: deleting a board, a column or a link, moving a column to another board, importing a column file, and adding a link by dragging it in from outside. It also refuses when your data changed in the meantime, reporting "Could not restore — the surrounding data changed after deletion." — which is what stops it from overwriting newer work from another computer.

MorrowTab says a board, column or list is full

The ceilings are 30 boards, 40 columns per board (120 in total), 200 links per column and 250 in total, and 20 search engines per board (80 in total), inside a 100 KB sync budget. The usage line in Settings shows where you stand, using exactly the arithmetic a save uses. See How much MorrowTab can hold.
